# CPIExtract vs DrugBank KEGG enrichment analysis

This folder contains a self-contained Jupyter workflow for comparing the KEGG pathway enrichment profiles obtained from CPIExtract-derived targets versus DrugBank targets.

The analysis is intended to support Figure 1, panels G and H.

## Scientific Goal

The central question is whether using CPIExtract target annotations changes the functional interpretation of compounds relative to using DrugBank targets.

For each compound matched between CPIExtract and DrugBank, the workflow compares KEGG pathway enrichment under both target definitions. The comparison is made across three CPIExtract target filtering levels:

- all CPIExtract targets;
- CPIExtract targets with `ave_pchembl >= 3`;
- CPIExtract targets with `ave_pchembl >= 6`.

The pChEMBL filters test whether enrichment differences persist when CPIExtract associations are restricted to stronger compound-target evidence.

## Analysis Steps

1. Load CPIExtract compound-target associations.

   The notebook reads `CPIE_FB_final_v2.csv`, keeps valid HGNC gene symbols, standardizes identifiers, and uses DrugBank InChIKey when available for compound matching.

2. Parse or load DrugBank compound-target annotations.

   DrugBank is read from the XML ZIP, or more commonly from the cached parsed table in `cache/`. Human protein targets, InChIKeys, DrugBank IDs, compound names, and ATC codes are retained.

3. Build target sets for each source.

   CPIExtract target sets are built separately for the three filtering levels. DrugBank target sets are built from curated human targets. Compounds with fewer than the minimum number of targets are excluded from enrichment.

4. Match CPIExtract compounds to DrugBank compounds.

   Matching is based on full InChIKey. This gives paired CPIExtract and DrugBank target sets for the same compounds.

5. Apply threshold-matched DrugBank filtering.

   For the filtered CPIExtract analyses, DrugBank targets are intersected with the CPIExtract targets available at the same pChEMBL threshold:

   - `all`: CPIExtract all targets vs DrugBank all targets;
   - `pChEMBL >= 3`: CPIExtract targets with `ave_pchembl >= 3` vs DrugBank targets that are also present in that CPIExtract thresholded set;
   - `pChEMBL >= 6`: CPIExtract targets with `ave_pchembl >= 6` vs DrugBank targets that are also present in that CPIExtract thresholded set.

   This avoids comparing a filtered CPIExtract target set against an unfiltered DrugBank target set.

6. Run or load KEGG enrichment.

   Enrichment is performed with Enrichr through `gseapy` using the `KEGG_2021_Human` gene set library. By default, the notebook loads the precomputed enrichment table in `tables/`, so it does not need to contact Enrichr.

7. Compute CPIExtract minus DrugBank enrichment differences.

   Adjusted p-values are converted to `-log10(adj. p-value)`. Non-significant pathway enrichments are set to zero before comparing sources. The main quantity is:

   `delta = -log10(adj. p-value)_CPIExtract - -log10(adj. p-value)_DrugBank`

   Positive values indicate stronger pathway enrichment under CPIExtract targets; negative values indicate stronger enrichment under DrugBank targets.

8. Classify significance switching.

   Each compound-pathway pair is classified as:

   - `CPIExtract only`;
   - `DrugBank only`;
   - `Significant in both`;
   - `Neither`.

   For panel H, `Neither` pairs are excluded and percentages are computed over the retained significant classes.

9. Annotate natural versus drug compounds.

   Compounds with ATC codes `A11` or `V06` are treated as the nutritional/natural compound group. All remaining matched compounds are treated as the drug compound group.

## Folder Contents

- `cipextract_drugbank_kegg_enrichment.ipynb`: sequential Jupyter notebook.
- `data/`: raw input files required by the notebook.
  - `CPIE_FB_final_v2.csv`
  - `drugbank_all_full_database.xml.zip`
- `cache/`: parsed DrugBank cache and KEGG pathway annotation cache.
- `tables/`: precomputed enrichment table and tables regenerated by the notebook.
- `figures/`: final panel files in SVG, PNG, and PDF.

## Reproducibility

Open `cipextract_drugbank_kegg_enrichment.ipynb` from this folder and run all cells from top to bottom.

The two main reproducibility switches are:

- `FORCE_REPARSE_DRUGBANK = False`

  Uses the parsed DrugBank cache at `cache/drugbank_compounds_targets_atc_inchikey_v2.csv`.

  Set this to `True` only if you want to rebuild the parsed DrugBank table from `data/drugbank_all_full_database.xml.zip`. This is useful if the DrugBank ZIP changes, if the parsing logic is modified, or if you want to verify the parsed cache from scratch.

- `RUN_ENRICHMENT = False`

  Uses the precomputed threshold-matched enrichment table in `tables/` and does not contact Enrichr.

  Set this to `True` only if you want to recompute enrichment results. Recomputing requires `gseapy` and access to the Enrichr service.

These switches are independent. You can reparse DrugBank without recomputing Enrichr results, although if target sets change, enrichment should be recomputed for full consistency.

The final notebook cell prints a compact run summary and writes:

- `tables/kegg_enrichment_reproducibility_summary.json`;
- `tables/kegg_enrichment_session_info.json`.
